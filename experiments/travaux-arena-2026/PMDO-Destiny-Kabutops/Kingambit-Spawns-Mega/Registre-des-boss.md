# Les 18 maîtres du dojo Kingambit

Chaque finale s’ouvre avec **un maître et deux cadets**, tous en forme de base. Le tableau indique la pierre du maître, **pas** un équipement ajouté aux trois adversaires. Les noms des objets correspondent à ceux de l’addon d’origine.

| Type de l’épreuve | Maître | Cadets | Pierre compatible |
|---|---|---|---|
| Normal — Échos | Lockpin | Laporeille ×2 | Lopunnite |
| Feu | Braségali | Galifeu, Poussifeu | Blazikenite |
| Eau | Tortank | Carabaffe, Carapuce | Blastoisinite |
| Plante | Jungko | Massko, Arcko | Sceptilite |
| Électrik | Élecsprint | Dynavolt ×2 | Manectite |
| Glace | Oniglali | Stalgamin ×2 | Glalitite |
| Combat | Lucario | Riolu ×2 | Lucarionite |
| Poison | Ectoplasma | Spectrum, Fantominus | Gengarite |
| Sol | Laggron | Flobio, Gobou | Swampertite |
| Vol | Dracaufeu | Reptincel, Salamèche | Charizardite X |
| Psy | Alakazam | Kadabra, Abra | Alakazite |
| Insecte | Dardargnan | Coconfort, Aspicot | Beedrillite |
| Roche | Tyranocif | Ymphect, Embrylex | Tyranitarite |
| Spectre | Branette | Polichombr ×2 | Banettite |
| Dragon | Altaria | Tylton ×2 | Altarianite |
| Ténèbres | Démolosse | Malosse ×2 | Houndoominite |
| Acier | Métalosse | Métang, Terhal | Metagrossite |
| Fée | Gardevoir | Kirlia, Tarsal | Gardevoirite |

Le type de l’épreuve est celui du maître **avant** la transformation : Dracaufeu porte l’épreuve Vol et sa pierre mène à la forme X, qui change de type. Le test technique a chargé les 18 sprites Méga exacts dans PMDO 0.8.12. Pour les données précises (IDs, formes et positions), voir `Registre-des-boss.json` dans l’archive ; les traces sont dans `Preuves/Parcours-natif-18-finales.txt`.
