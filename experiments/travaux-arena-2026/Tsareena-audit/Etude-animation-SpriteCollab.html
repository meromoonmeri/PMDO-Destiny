Tsareena · référence

Méga-Tsareena · étude

Ce que montre cet essai : deux images originales générées pour le repos et deux pour le sommeil, sans effet fantaisiste. L’attaque est un blocage provisoire : deux dessins de robe plus la pose de repos, déplacés selon la trajectoire observée sur la référence ; ce ne sont pas 14 dessins originaux. Le passage repos-sommeil n’est pas encore animé. Les images brutes ont été conservées ; les copies d’aperçu sont détourées et redimensionnées.

Vérification SpriteCollab

  • Repos : 2 images, 30 + 30 ticks ; sommeil : 2 images, 30 + 35 ticks, une seule direction dans la planche de Tsareena.
  • Attaque : 14 images, durées 4, 2, 2, 2, 2, 2, 2, 3, 1, 1, 2, 2, 2, 2 ticks ; phase de retour après l’impact. Un tick = 1/60 s.
  • Restent à dessiner et raccorder : toutes les images uniques d’attaque, les autres directions, les actions manquantes, les ombres et les offsets ; ceci n’est pas un pack prêt pour SpriteCollab.
