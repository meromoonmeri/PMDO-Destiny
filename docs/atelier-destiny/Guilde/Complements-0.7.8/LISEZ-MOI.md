# Compléments de l'atelier — 0.7.8

Ces fichiers complètent les travaux d'atelier déjà présents dans le dépôt ; ce sont des ressources séparées, pas des objets posés automatiquement en jeu.

- `Accessoires/` contient le vestiaire autonome et le kit d'essai le plus récent. Les sources de ce dernier sont aussi intégrées au jeu dans ce commit. Les accessoires restent expérimentaux selon la morphologie.
- `Archives-accessoires/` conserve les deux anciens kits d'essai. Ils sont historiques : leurs patches ne doivent pas être ajoutés par-dessus la nouvelle version, qui les remplace.
- `Objets/` contient le catalogue et quatre kits de dix objets, soit 40 objets produits sur 60 prévus. Ce sont des sprites 1× pour l'atelier, une orientation, non installés dans le jeu. Les générations haute définition et sources de reconstruction complètes restent dans l'espace de travail initial et ne sont pas copiées ici.

La version complète des ateliers et leurs crédits se trouvent dans le reste de `docs/atelier-destiny/`. Les fichiers d'origine des objets et accessoires et leur état restent inchangés dans l'espace de travail. Méga-Tsareena est exclue.
