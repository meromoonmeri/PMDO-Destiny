Ce qui vient du jeu

Scènes vérifiées : le déblocage de l’Île Blizzard (s02p0101) et le trajet Bourg-Trésor → Caverne Saline (m23a0101). Le jeu lance la fanfare avec le repère clignotant, après le dégagement des nuages.

Reconstitution : Pikachu est un choix de héros, le trajet vers l’Île Blizzard assemble deux vrais points avec le moteur de déplacement, et le temps de lecture des messages est réglé pour l’aperçu. Seuls les repères utiles aux scènes sont affichés. Le terrain DS et ton fond nu sont deux calques alternatifs ; ton PNG reste inchangé.
