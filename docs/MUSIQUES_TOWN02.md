# Musiques Town02 importées

Bibliothèque de 213 titres. Les 51 pistes téléchargées depuis le dossier Drive ont été comparées bit à bit à town02-main GitHub ; les 162 restantes proviennent de town02-main GitHub et ont été vérifiées contre leurs empreintes SHA-256 LFS, mais pas individuellement comparées au Drive.

62 fichiers déjà présents et identiques n'ont pas été modifiés. Le thème de Wigglytuff a été ajouté avec la carte. 146 autres morceaux absents sont ajoutés. Pour les quatre noms déjà utilisés par des fichiers différents, les originaux Destiny restent intacts et les versions Town02 sont ajoutées avec le suffixe ` [Town02]` : Aftermath, Boss Battle, Icicle Forest et Tiny Woods.
